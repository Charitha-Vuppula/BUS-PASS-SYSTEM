# Bus Pass Management System

A web-based Bus Pass Management System designed to simplify the process of applying for, managing and accessing bus passes through a digital platform.

## About the Project

The Bus Pass Management System is a web application developed as an academic major project using the MERN stack.

The project aims to provide a convenient digital alternative to traditional bus pass management by organizing user information, pass applications and related operations through a centralized platform.

## Objectives

- Digitize the bus pass application and management process.
- Provide an organized interface for users.
- Simplify bus pass-related workflows.
- Improve accessibility and reduce manual administrative effort.

## Technology Stack

Development:
- MongoDB
- Express.js
- React.js
- Node.js

Additional Technologies & Tools:
- Figma AI : UI/UX prototyping
- Antigravity : AI-assisted website development
- GitHub : Project repository and version management

## Key Features

- User registration and authentication
- Digital bus pass application and management
- Pass-related information and status management
- QR code-based pass functionality
- User profile management
- Administrative operations
